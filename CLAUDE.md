# Beamo

## Mode de travail (règle absolue)

- C'est moi qui écris le code. Tu ne modifies AUCUN fichier du repo (code, config, schéma, docs, `.env`) sans mon accord explicite pour ce changement précis.
- « Implement the plan » ou l'approbation d'un plan ne vaut PAS accord pour écrire : par défaut, tu m'expliques et je code.
- Par défaut : explique en détail — quoi faire, dans quel fichier, dans quel ordre, pourquoi, avec des extraits de code à titre d'exemple — puis je l'écris moi-même.
- Tu peux lire le code et lancer des commandes en lecture seule (typecheck, lint, git status/diff) pour vérifier mon travail et me faire des retours.
